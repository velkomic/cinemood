# CineMood

CineMood helps visitors discover movies and keep a personal collection of saved choices.

## Language

**Catalog**:
The set of movies available for CineMood to search and recommend.
_Avoid_: User database

**Recommendation**:
A movie suggested in response to a visitor's current request, accompanied by an explanation supported by its catalog details.

**Collection**:
A visitor's saved movies, which they can view and remove on return visits in the same browser.
_Avoid_: Personal database
