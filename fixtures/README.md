# Original fixture catalog

These four films, titles, and descriptions are fictional, authored for CineMood.
The repository contributor dedicates this fixture metadata to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
They contain no TMDB records or images. They demonstrate retrieval behavior;
they are not a real movie recommendation catalog or a relevance evaluation.

The normal loader sends these descriptions to OpenAI for actual embeddings.
Only the test/demo HTTP server returns deterministic synthetic vectors.
